YOUR QUESTIONS ANSWERED:

1. DO WE NEED A WEBSITE?
   YES. Absolutely required for:
   • Trust signal for paid users
   • Legal compliance (Privacy + Terms for Chrome Web Store)
   • Marketing hub (SEO content, pricing clarity, support center)
   • Future scaling (hub for other extensions)

2. WHAT PAGES DO WE NEED?
   Essential (v1.0):
   • Homepage (/) — hero, features, social proof, CTA
   • Features (/features) — deep dive on inspector, guides, cascade
   • Pricing (/pricing) — Free vs Pro vs Team table + FAQ
   • FAQ (/faq) — 20-30 common questions
   • Privacy (/privacy) — required for CWS
   • Terms (/terms) — required for CWS
   • Support (/support or /contact) — contact form + help links

   Nice-to-have (v1.1+):
   • Blog (/blog) — SEO content, tutorials, use cases
   • Changelog (/changelog) — version history, transparency
   • Status page — link to status.io (only if you have servers)

3. DO WE NEED AN ADMIN PANEL?
   NO, not yet. 
   
   Phase 1 (now → $1K MRR): Use existing tools
   • Revenue: ExtensionPay dashboard
   • Support: email inbox + GitHub Issues + Canny.io
   • Analytics: Chrome Web Store dashboard
   
   Phase 2 ($1K-5K MRR): Add lightweight admin panel
   • Dashboard showing MRR, churn, user count
   • Support ticket queue
   • In-app announcements
   
   Phase 3 ($5K+ MRR): Full analytics
   • User cohorts, feature adoption, error tracking
   • Build if/when you need it

4. TECH STACK RECOMMENDATION: FRAMER (fastest launch)
   • 2-3 hours to go live
   • Beautiful templates, no coding
   • Free tier + $20/mo custom domain
   • Alternative: Next.js + Vercel (more control, 4-6h to build)
